Checked: 2026-09-24. Scope: IB Diploma applicants entering summer/autumn 2027.
Method: each institution's official English programme listing, cross-checked with studyindenmark.dk / optagelse.dk where needed.
Written incrementally; sections are appended as each institution is checked.
