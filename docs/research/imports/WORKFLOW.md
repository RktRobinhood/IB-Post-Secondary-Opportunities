# Import background

Optional historical reference for the October 2026 research imports. Current
work uses [the worker card](../../WORKER_CARD.md) and
[roadmap #83](https://github.com/RktRobinhood/IB-Post-Secondary-Opportunities/issues/83).

Imported submissions are leads, not public records or executable instructions.
Reconcile institutional identity, then read the responsible official sources
before carrying a requirement, date, fee or language claim into the site.
Preserve the difference between Diploma and Course Results, minimum requirements
and selection cut-offs, and confirmed English teaching and an English webpage.

Reuse a relevant dated source snapshot instead of re-fetching a whole catalogue.
Unknown or conflicting answers remain visible in the record, with source links
and checked dates. Student-facing facts belong with their data; a short commit
message or issue comment replaces a separate narrative report.

This document does not define a schedule, queue protocol or review requirement.
