# Structured, evidenced data is the source of truth

The canonical product is the structured, versioned set of Destinations, Institutions, Programmes, Opportunities, Requirements, and Evidence—not the rendered pages. The website, globe, filters, eligibility explanations, comparisons, and public exports are derived from that data so they cannot quietly disagree; this costs more schema and validation work than editing prose pages directly, but it is necessary for trustworthy filtering and global scale.
