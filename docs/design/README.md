# Design reference

`university-page-mockup.html` is the agreed visual direction for the site, shown
on one university page (University of Groningen, built from `data/schools/nl-rug.json`
and the stored photographs). Open it in a browser at desktop and phone width.

It is a reference for look and layout, not production code. The page's design
tokens are the `:root` block at the top of its `<style>`.

What the owner asked for, in their words: light by default, cozy and organic,
bespoke, "not a collection of boxes", and an actual improvement on the current
site rather than a different look for its own sake.
